# HP Bar Detector

Программа для автоматического определения процента здоровья персонажа в игре с помощью обычной веб-камеры, направленной на экран.

## Возможности
- Захват экрана через веб-камеру.
- Геометрическая коррекция перспективы по ArUco-маркерам (гомография).
- Распознавание зелёной полоски здоровья по цветовой маске (HSV).
- Экспоненциальное сглаживание измерений для стабильного отображения процента.
- Детекция активации умений по резкому изменению яркости (опционально).
- Подавление бликов с помощью CLAHE и гамма-коррекции.
- Ручная настройка HSV-диапазона через трекбары.
- Сохранение настроек ROI в текстовые файлы.

## Требования
- Python 3.8 или выше
- Веб-камера
- Библиотеки: OpenCV, NumPy
